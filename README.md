# weichengmin.github.io

A lightweight academic website for Weicheng Min. It is plain HTML/CSS, so GitHub Pages can serve it directly without a build step.

## Publish on GitHub Pages

1. Create a **public** GitHub repository named exactly `weichengmin.github.io`.
2. Upload everything in this folder to the repository root.
3. In GitHub, go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. After a minute or two, visit `https://weichengmin.github.io`.

## Update papers

Edit `research.html`. Each paper is an `<article class="paper"> ... </article>` block. You can duplicate a block to add a paper.

## Files currently linked externally
